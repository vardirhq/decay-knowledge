# Cookbook

Cookbook pages are short task-oriented answers for developers who already know the basics.

## Movement and input

- Move an entity with an input axis
- Move in two dimensions with a vector
- Read a gamepad by player slot
- Detect a just-pressed action
- Point or aim toward a position
- Make a camera follow gameplay

## World and entities

- Spawn a prefab
- Find/query an entity
- Destroy or remove gameplay objects
- Read and change transforms
- Keep a reference to another script safely

## Physics and collisions

- Give an entity velocity
- Apply an impulse
- Detect a collision or sensor interaction
- Use collision layers/masks

## Game architecture

- Damage a specific script
- Broadcast that something happened
- Keep score or other shared game state
- Implement a cooldown/timer
- Restart/reset a gameplay state

## Presentation

- Play and change an animation
- Play a sound
- Trigger an effect
- Update UI from gameplay state
- Save and restore progress

Each recipe should contain: goal, smallest checked example, explanation, common mistake, and links to the exact language/API reference.
