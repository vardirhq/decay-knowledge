Learn Decay / Getting started

Your first Decay script

A Decay script adds gameplay behaviour to an entity. Start with the smallest useful thing: a value you can tune in Sindri and code that runs every frame.

What you'll learn

Scripts, exported fields, typed values, functions, update, and why dt exists.

Declare a script

script Player {
    @export
    var speed: f32 = 220.0;
}

script Player declares a gameplay script type. @export makes speed editable from Sindri instead of burying tuning values in source.

Run behaviour every frame

fn update(dt: f32) {
    let direction = Input.axis("move_left", "move_right");
    this.transform.position.x += direction * speed * dt;
}

The engine calls update while the script is active. Multiplying movement by dt makes speed depend on time rather than frame rate.
